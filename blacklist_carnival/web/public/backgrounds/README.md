# Background artwork slots

Drop your own artwork here (PNG or JPG), then rebuild the NUI (`npm run build` in `web/`).
A missing file is fine — the screen falls back to the built-in dark gradient.
Recommended: 1920x1080, dark, low-contrast so text stays readable. **No clown imagery.**

| File name (`.png` or `.jpg`) | Screen |
|---|---|
| `admin` | Owner/admin configurator |
| `staff` | Event staff panel |
| `hub` | Player hub (`/carnival`) |
| `ticket` | Ticket card |
| `leaderboard` | Leaderboard |
| `wheel` | Wheel of Misfortune |
| `fortune` | Fortune Teller |
| `deception` | Hall of Deception terminal |
| `results` | Final results banner |
